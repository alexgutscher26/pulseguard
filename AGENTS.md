# AGENTS.md

PulseGuard: Turborepo + Bun workspaces monorepo — Cloudflare-edge monitoring platform. Two Cloudflare Workers (`apps/web` Next.js 16 via OpenNext, `apps/worker` monitoring engine), plus Expo app, Docker probe, CLI. Deep docs: `README.md`, `ARCHITECTURE.md`.

## Commands (repo root, Bun only)

- Install: `bun install` (postinstall runs `db:generate`). Never npm/yarn — `bun.lock` is canonical (must stay LF, see `.gitattributes`).
- Dev: `bun run dev` (turbo, excludes infra/probe). `predev` runs `scripts/sync-env.js`: copies root `.env` → `apps/web/.env` and `apps/worker/.dev.vars`. After editing root `.env`, re-run `bun run predev` or restart dev — changes don't propagate otherwise.
- Pre-commit gate (exact CI order, all required): `bun run check` (oxlint + **oxfmt --write**, which auto-formats) → `bun run check-names` → `bun run check-types` → `bun run build` → `build-storybook`, `check-size`, `check-deps`. `oxfmt`, not prettier, is the enforced formatter; `bun run format` (prettier) also exists.
- `bun run check-names` fails on any file with an uppercase char under `apps/*/src` or `apps/*/app` — source files must be kebab-case (enforced by `scripts/check-filenames.js`, run in CI).
- Focused: `bunx oxlint <path>`, `bun --cwd apps/web run check-types`.
- DB: Prisma 7 + pg driver adapter. `bun run db:push` (dev sync), `db:migrate` (required for schema changes), `db:generate` (client output → `packages/db/src/generated`), `db:studio`. Schema in `packages/db/prisma/schema/`. Needs a real Postgres (`docker compose up -d`: postgres:16, redis:7, mailhog at :8025).
- Worker dev: `bun run dev:worker` → `wrangler dev --test-scheduled`; cron triggers live in `apps/worker/wrangler.jsonc`.
- Tests: `bun --cwd apps/web vitest run` (Storybook/Vitest component tests via `@storybook/addon-vitest`, `.stories.tsx` with `play` functions). `bun --cwd apps/e2e test` (Playwright — needs web app + DB running at 127.0.0.1:3000; env read from `apps/web/.env`).

## Conventions

- **Git branch is `master`** (changesets `baseBranch` and both release workflows target master). CONTRIBUTING.md and `ci.yml` still say `main`/`develop` — stale; the CI job only triggers for PRs targeting main/develop, so CI checks will NOT run on a master-based PR. Branch from `master`.
- Commits: Conventional Commits, enforced by husky + commitlint (header ≤ 100 chars; types: `feat fix chore docs refactor perf test build ci style revert`). Scopes = workspace names (`web worker cli native probe db api auth core env types shared config infra email wasm-parser`). Release versioning is derived from commit types.
- Releases: push a `vX.Y.Z` tag → `release.yml` builds ghcr.io images (`pulseguard-web`, `pulseguard-probe`), packages the Helm chart, creates the GitHub Release. `CHANGELOG.md` is generated by git-cliff (`cliff.toml`) — never hand-edit. A changesets flow (`version.yml`) also exists.
- Shared deps (zod, typescript, next, @prisma/client, tRPC…) are pinned in the root `catalog:` block of `package.json` — reference them with `"catalog:"`, don't re-pin versions.
- Type-sharing via `packages/types`; runtime validation with Zod; tRPC routers in `packages/api`. Named exports only (React components may default-export).

## Architecture gotchas

- Two Workers: `apps/web` (OpenNext is part of the `build` script: `next build && opennext build -s`) and `apps/worker` (cron loop every minute; Durable Objects `LatencyAggregator` + `MonitorChannel`; KV `DNS_CACHE`; queue bindings are commented out for the free plan — keep them that way).
- Worker runtime: `nodejs_compat` is enabled in wrangler.jsonc, but stay on native `fetch`/Web Crypto; keep the bundle lean.
- `packages/wasm-parser` is a standalone Rust crate (`src/lib.rs` only — no Cargo.toml/package.json committed) not wired into any build. Real payload validation lives in `apps/worker/src/lib/payload-parser.ts` and `apps/web/src/lib/payload-parser.ts`.
- `.agent/` is a third-party "Antigravity" agent framework (agents/skills/workflows for a different tool) — not OpenCode config; ignore unless asked.
- `.env*` files are gitignored; only `.env.example` is committed (`DATABASE_URL`, `BETTER_AUTH_SECRET` ≥32 chars, `BETTER_AUTH_URL` required).
